# EmbyBoss 外部账号适配器

这是官方 Plugin V2 适配器，只负责把 Sakura EmbyBoss 使用的 Emby 账号管理协议翻译成
EM 的受控能力调用。Provider 鉴权、HMAC 防重放、隐藏用户、EA 生命周期、线路授权和审计
仍由 EM 主进程托管。

插件没有数据库、Express、Prisma、EA API Key 或任意网络访问权。每项账号操作都在
`plugin.json` 中单独声明、由管理员批准，运行时只能访问当前已鉴权 Provider 的账号。

## 管理页（2.2.5）

管理页默认打开“接入总览”，只读取 Provider 和账号统计，不在首屏加载账号分页或审计分页。
创建、接入维护、账号、审计和配置说明通过页面 Action 切换：

- `接入总览`：查看接入状态、账号数和待处理数，并进入某个接入的管理页。
- `创建接入`：单独填写接入名称和目标 EA；创建后的密钥只在本次响应中显示。
- `接入管理`：根据当前状态直接显示“启用接入”或“停用接入”，并提供“重新生成接入密钥”。
- `维护`：将原来的“全量对账”改名为“检查并修复账号状态”，只在具体接入的维护区域显示。
- `账号管理`与`审计记录`：分别按需读取分页数据，筛选和翻页不再与默认总览混在一起。

旧版本缓存页面仍可能提交 `delete` Provider Action；后端分支保留以兼容历史页面，但 2.2.5
不再把“删除空接入”作为普通 UI 操作显示。它只允许删除没有活动账号的 Provider，未来应放在
宿主提供的危险操作确认区域，并明确命名为“删除接入（仅无活动账号）”。

插件只把 Provider 摘要和账号视图的非敏感状态写入 `external-admin/state-v1`。创建或重新生成
接入密钥时，密钥只放在本次 Action 响应中，不写入插件存储、审计正文或普通页面状态；关闭或刷新
后只能再次生成新密钥。

全量维护任务由宿主后台运行。页面显示进行中百分比、已检查、已修复、失败、重试和失败示例，
并提示任务可能产生较多 EA 请求；日常无需执行。接入状态则使用 EM 提供的受控健康检查，插件
本身拿不到 EA 地址或 Webhook 密钥。

## 宿主侧后续能力

当前插件使用声明式页面和 Action 兼容现有宿主。为进一步减少操作层级，EM 宿主后续可按以下顺序
支持而不改变本插件的 Provider 或 SDK 语义：

1. 页面级 Tabs，将 Action 视图切换替换为真正的页面标签页；
2. 标题栏右侧 Actions，把“刷新”和“创建接入”移到标题栏；
3. 表格行级 Actions，把“管理”按钮放到每个接入行右侧；
4. 危险操作确认，把删除接入放入专门的危险操作区；
5. 一次性密钥复制按钮，减少密钥暴露在普通页面文本中的时间；
6. 移动端操作菜单，以及完整的键盘焦点和无障碍标签。

本次 2.2.5 只修改 `plugins/embyboss-adapter/`，没有修改 SDK、Schema、EM 核心或其他插件。

## 评审用静态原型

`design/admin-console-prototype.html` 是本 PR 附带的离线交互原型，方便维护者直接下载到本地后用浏览器打开，查看“总览 → 创建接入 → 一次性密钥 → 接入管理 → 启用/停用 → 重新生成密钥 → 检查并修复账号状态 → 账号/审计”的完整流程。

这个文件只用于设计评审，不是插件运行时页面：它不被 `plugin.json` 或 `ui/admin.json` 引用，不包含外部依赖、网络请求、生产地址、真实账号或真实密钥。插件运行时仍使用声明式 `ui/admin.json`，原型中的数据和动作均为模拟值。
