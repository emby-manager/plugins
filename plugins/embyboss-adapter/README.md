# EmbyBoss 外部账号适配器

这是官方 Plugin V2 适配器，只负责把 Sakura EmbyBoss 使用的 Emby 账号管理
协议翻译成 EM 的受控能力调用。Provider 鉴权、HMAC 防重放、隐藏用户、EA 生命周期、
线路授权和审计全部仍由 EM 主进程托管。

插件没有数据库、Express、Prisma、EA API Key 或任意网络访问权。每项账号操作都需在
`plugin.json` 单独声明、由管理员批准，并且运行时只能访问当前已鉴权 Provider 的账号。

## 管理页

管理页默认只读取接入总览，不再把创建表单、账号分页和审计分页一次性堆在首屏。创建接入、
接入管理、账号管理、审计记录和配置说明由独立 Action 视图承载：账号与审计只在进入相应
视图时按需读取，筛选和翻页会保留当前上下文。

具体接入页根据当前状态只显示“启用”或“停用”中的一个操作，并把重新生成密钥、检查并修复
账号状态集中在维护区。一次性密钥只出现在创建或轮换后的当前响应，不写入插件 KV 状态。
维护任务在宿主后台运行，页面可刷新查看进度、限流重试次数与失败诊断；接入健康状态由 EM
受控能力返回，插件本身拿不到 EA 地址或 Webhook 密钥。

## 限流、删除重建与健康状态

适配器保留宿主返回的 401、403、429、5xx 和 `Retry-After`，让 EmbyBoss 能区分权限、
限流与临时故障。批量账号对账由 EM 宿主串行限速、指数退避并按账号幂等执行；删除因
限流停在中间时会在下一次对账或同名重建前补完，不会把待删除身份误当作新账号。

`GET /Sessions` 通过声明的 `external-account.provider.health.read` 能力读取当前接入的
安全健康快照。EA 在线时返回合法的空会话列表，离线或配置错误时返回 503；这只是连接
状态降级，不伪造真实播放数据，也不会向插件暴露 EA 地址、Webhook 密钥或数据库。

用户名和错误状态都由适配器做有界验证。带 `NewPw`、`Password` 或 `Pw` 的改密请求
会原样传给已声明、已授权的密码写入能力，不裁剪首尾字符。`ResetPassword=true` 且没有
新密码时按官方 Emby 语义清除密码；EmbyBoss 会先清除、再提交 `NewPw`，两步都必须成功。
